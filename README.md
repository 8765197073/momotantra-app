# MoMo Tantra & Ichheydotcom

## 🚀 Overview
A hybrid e-commerce and food service application designed for local businesses in Konnagar. The platform supports seamless ordering for food (MoMo Tantra) and personalized gifts (Ichheydotcom).

## 🛠 Tech Stack
* **Frontend:** React / Next.js
* **Database/Backend:** Firebase / Supabase (or relevant backend)
* **Payments:** Integration with Stripe/Razorpay
* **Deployment:** Vercel

## 🔑 Key Features
* **Dual-Business Interface:** Unified platform for food and gift services.
* **Smart Cart System:** Coupon code application and real-time subtotal calculation.
* **Order Tracking:** Integrated live order tracking status.
* **Admin Dashboard:** Simplified backend for managing orders and inventory.
